# 행성 지도 시제품 (Godot 4)

구형 행성 위의 육각 타일 지도를 만드는 시제품입니다. 지형과 기후는 손으로 칠하지 않고 아래 순서로 계산합니다.

1. **육각 격자**: 정이십면체를 세분해 구를 덮습니다. 모든 칸은 육각형이고, 수학적으로 꼭 필요한 오각형 12칸만 섞여 있습니다.
2. **판 구조**: 무작위로 판을 나누고 판마다 움직임을 줍니다. 판이 부딪히는 곳에는 산맥, 해구, 호상 열도가 생기고, 벌어지는 곳에는 열곡과 해령이 생깁니다.
3. **고도**: 지각 성향, 판 경계 효과, 노이즈를 더한 뒤, 정한 육지 비율에 맞춰 해수면을 정합니다.
4. **기온**: 위도, 고도 (1km 당 6.5°C 감소)로 정합니다.
5. **기압과 바람**: 적도 저압대, 위도 30° 고압대, 위도 60° 저압대, 극고압대의 3세포 순환에서 기압경도력을 구하고, 코리올리 효과로 북반구는 오른쪽, 남반구는 왼쪽으로 꺾습니다. 그 결과 무역풍, 편서풍, 극동풍이 저절로 생깁니다.
6. **강수**: 바다에서 생긴 수증기가 바람을 타고 내륙으로 이동하며 조금씩 비로 내립니다. 산을 넘을 때 크게 비를 뿌리고, 산 너머는 비그늘이 되어 건조해집니다.
7. **물**: 바다에서 거꾸로 채워 나가는 방식(Priority-Flood)으로 모든 칸의 하류 방향을 정하고, 유출량을 누적해 강을 만듭니다. 물이 고이는 곳은 호수, 평탄하고 물이 많은 저지대는 습지가 됩니다.
8. **생물군계**: 기온과 강수량으로 툰드라, 타이가, 스텝, 사막, 사바나, 열대 우림 등을 정하고, 고도와 기복으로 구릉과 산지를 나눕니다.

## 실행

1. [Godot 4.3 이상](https://godotengine.org/download) 표준판(.NET 아님)을 설치합니다.
2. Godot 프로젝트 관리자에서 **가져오기**를 누르고 이 폴더의 `project.godot`을 고릅니다.
3. 처음 열 때 글꼴을 가져오느라 몇 초 걸립니다. 그다음 F5(실행)를 누르면 됩니다.

## 조작

- 마우스 드래그: 행성 회전 / 휠: 확대·축소 / 클릭: 타일 정보 고정 / 방향키: 회전 / R: 북쪽 정렬
- 왼쪽 패널: 시드, 크기, 육지 비율, 판 개수, 평균 기온, 강수량, 강의 양을 바꾸고 "세계 생성"
- 보기: 지형, 고도, 기온, 강수량, 판 구조, 기압과 바람

크기는 작게 2,562칸, 보통 10,242칸, 크게 40,962칸입니다. 크게는 생성에 몇 초 걸립니다.

## 파일 구성

- `scripts/hex_sphere.gd`: 구형 육각 격자와 이웃 관계
- `scripts/world_gen.gd`: 판 구조, 고도, 기후, 강, 생물군계 생성
- `scripts/planet_view.gd`: 3D 메시 (타일 기둥, 산 봉우리, 강, 바람 화살표, 대기)
- `scripts/main.gd`: 장면 구성, 카메라, UI
- `tools/stats.gd`: 생물군계 비율을 출력하는 점검용 스크립트 (`godot --headless -s tools/stats.gd`)
