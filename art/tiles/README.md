# 타일 위 그림 (임시 그림)

행성 칸 위에 얹는 식생, 시설물, 도로 그림입니다. 나중에 다른 그림으로 바꾸기 쉽도록 만든 임시 그림입니다.

## 바꾸는 방법

- 같은 이름의 파일을 덮어쓰면 됩니다. SVG 와 PNG 를 모두 쓸 수 있습니다.
- 파일 이름을 바꾸려면 `scripts/tile_art.gd` 의 `ART` 목록에서 경로만 고치면 됩니다.
- `ART` 에서 지운 항목은 그림 없이 색만 칠합니다.
- 어떤 칸에 어떤 그림을 쓸지는 같은 파일의 `veg_key`, `struct_key` 에 있습니다.
- 그림이 제대로 읽히는지는 `godot --headless -s tools/art_sheet.gd -- atlas.png` 로 한 장에 모아 볼 수 있습니다.

## 그림 규칙

- 정사각형 (SVG 는 viewBox 256x256 기준). 가운데가 칸 중심이고 위쪽이 북쪽입니다.
- 정사각형의 너비가 육각 칸의 꼭짓점-꼭짓점 거리입니다. 칸 안에 보이는 부분은 가운데에서 반지름 약 110px (256px 기준) 원 안쪽이므로, 그 안에 그립니다.
- 배경은 투명하게 둡니다. 칸의 지형 색 위에 얹힙니다.
- `road.svg` 는 도로 한 갈래입니다. 가운데에서 오른쪽(+x) 변 가운데(x≈239)까지 그리고, 이웃 칸으로 이어진 방향마다 돌려서 겹쳐 그립니다.
- 방치된 시설은 원래 그림을 어둡게, 폐허가 되면 `ruin.svg` 를 씁니다.

## 목록

| 파일 | 쓰이는 곳 |
|---|---|
| grass | 초지 (습윤) |
| grass_dry | 초지 (건조·반건조) |
| tundra | 초지 (한대) |
| forest | 숲 (열대·온대) |
| forest_boreal | 숲 (냉대·한대) |
| jungle | 밀림 |
| wetland | 습지 |
| desert | 건조한 맨땅 |
| farm, district, shrine, mine, lumber, irrigation, camp, fishery | 시설물 |
| ruin | 폐허가 된 시설 |
| road, road_alone | 도로 갈래, 이웃 도로가 없는 도로 |

모두 이 프로젝트를 위해 새로 그린 그림입니다.
