# 타일 위 그림 (임시 그림)

행성 칸 위에 얹는 그림입니다. 나중에 다른 그림으로 바꾸기 쉽도록 만든 임시 그림이며, 모두 이 프로젝트를 위해 새로 그렸습니다.
그림 목록과 어떤 칸에 어떤 그림을 쓸지는 `scripts/tile_art.gd` 에 있습니다.

## 세 가지 그림

| 종류 | 폴더 | 하는 일 |
|---|---|---|
| 바닥 (GROUND) | `ground/` | 1층 지형·기후로 정하는 바닥 무늬. 식생을 모두 걷어 내도 남는다. 이음매 없이 반복된다. |
| 납작한 그림 (DECAL) | 이 폴더 | 칸 위에 깔리는 그림. 밭, 광장, 웅덩이, 도로, 해안, 강둑, 그림자. |
| 세운 그림 (SPRITE) | `sprites/` | 나무, 집, 천막처럼 바닥에 세우는 그림. 카메라를 향해 서고 발밑에 그림자가 깔린다. |

## 바꾸는 방법

- 같은 이름의 파일을 덮어쓰면 됩니다. SVG 와 PNG 를 모두 쓸 수 있습니다.
- 파일 이름을 바꾸려면 `scripts/tile_art.gd` 의 `GROUND`, `DECAL`, `SPRITE` 목록에서 경로만 고치면 됩니다. 목록에서 지운 항목은 그리지 않습니다.
- 숲에 나무를 몇 그루 세울지, 마을에 집을 어디에 둘지는 같은 파일의 `sprites_for`, `STRUCT_SPRITES` 에 있습니다.
- 그림이 제대로 읽히는지는 `godot --headless -s tools/art_sheet.gd -- 저장폴더` 로 한데 모아 볼 수 있습니다.

## 그림 규칙

- 바닥: 256x256, 이음매 없이 반복되는 무늬. 칸 두 개쯤을 덮는 크기로 찍힙니다. `art/tools/gen_ground.py` 로 만들었습니다.
- 납작한 그림: 256x256. 가운데가 칸 중심이고 위쪽이 북쪽입니다. 정사각형 너비가 육각 칸의 꼭짓점-꼭짓점 거리이므로, 칸 안에 보이는 부분은 가운데에서 반지름 약 110px 원 안쪽입니다. 배경은 투명하게 둡니다.
  - `road.svg` 는 도로 한 갈래입니다. 가운데에서 오른쪽(+x) 변 가운데(x≈239)까지 그리고, 이웃 칸으로 이어진 방향마다 돌려서 겹쳐 그립니다.
  - `shore.svg` 는 가로로 늘여 쓰는 띠입니다. 위 절반이 물, 아래 절반이 땅이고 가운데 가로선이 물가입니다.
  - `river_bank.svg` 는 강줄기를 따라 늘여 쓰는 띠입니다. 가운데가 강, 위아래가 흙둑입니다.
- 세운 그림: 128x128. 바닥에 닿는 점이 (64,124) 입니다. 그림자는 그리지 않습니다 (따로 깔림).
- 방치된 시설은 원래 그림을 어둡게, 폐허가 되면 `ruin.svg` 와 `ruin_wall`, `ruin_column` 을 씁니다.
