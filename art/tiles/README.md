# 타일 위 그림 (임시 그림)

문명3 처럼 상황마다 다른 2D 그림을 골라 쓰는 틀입니다. 지금 그림은 모두 이 프로젝트를 위해 새로 그린 임시 그림이고,
나중에 같은 이름의 파일을 넣으면 그대로 바뀝니다. **폴더에 파일을 넣기만 하면 게임이 읽습니다** (코드에 목록이 없습니다).
어떤 칸에 어떤 이름을 고르는지는 `scripts/tile_art.gd` 에 있습니다.

## 파일 이름 규칙

| 규칙 | 뜻 | 예 |
|---|---|---|
| `이름.svg` | 기본 그림 | `decal/grass.svg` |
| `이름.2.svg`, `이름.3.svg` ... | 같은 그림의 변주. 칸마다 정해진 하나를 골라 반복이 덜 보이게 한다. 몇 장이든 된다. | `ground/grass.2.svg` |
| `가_나_다.svg` | 세 칸이 만나는 꼭짓점의 완성 그림 (아래 "꼭짓점 조합") | `combo/grass_grass_shallow.svg` |
| `.png` | 같은 이름의 SVG 대신 PNG 를 쓴다 | `sprite/house.png` |

## 바닥은 꼭짓점 단위로 그린다

육각 칸의 변에서 그림이 직선으로 끊기지 않도록, 바닥은 칸 단위가 아니라 **세 칸이 만나는 꼭짓점마다 하나의 삼각형**으로 그립니다.
삼각형의 세 꼭짓점이 세 칸의 가운데이고, 그 안에서 세 칸의 바닥 무늬, 물, 물가, 물거품을 한 번에 섞어 그립니다.
그래서 경계는 직선이 아니라 구불구불한 자연스러운 선이 되고, 바다와 땅이 닿는 곳에는 물가 무늬와 물거품이 생깁니다.
덮어 얹는 투명 띠는 더 이상 쓰지 않습니다.

### 꼭짓점 조합 그림 (`combo/`)

자동 합성 대신 직접 그린 완성 그림을 쓰고 싶은 조합이 있으면 `combo/` 에 넣습니다. 문명3 의 조합별 그림과 같은 방식입니다.

- 이름: 세 칸의 겉모습 이름을 **반시계 방향** 순서로 `_` 로 잇습니다. 같은 조합의 돌린 이름(`a_b_c`, `b_c_a`, `c_a_b`) 중 사전순으로 가장 앞선 것 하나만 쓰면 되고, 게임이 알맞게 돌려 붙입니다.
- 그림: 256×256 안에 정삼각형. 첫 번째 이름의 칸이 위 꼭짓점 (128,18), 두 번째가 왼쪽 아래 (18,208), 세 번째가 오른쪽 아래 (238,208) 입니다.
- 불투명하게 그리면 자동 합성을 완전히 대신하고, 투명한 곳은 자동 합성이 비쳐 보입니다.
- 변주도 됩니다: `grass_grass_shallow.2.svg`.
- 조합 그림이 없으면 자동 합성으로 그립니다. 그러니 눈에 띄는 조합부터 하나씩 채워 가면 됩니다.

### 칸의 겉모습 이름

땅: `grass` (습윤), `plains` (반건조), `desert` (건조), `tundra` (한대), `snow` (눈·빙설, 눈 덮인 산), `rock` (산지)
물: `deep` (깊은 바다), `shallow` (얕은 바다), `lake` (호수), `ice` (해빙)

## 폴더

| 폴더 | 크기 | 하는 일 |
|---|---|---|
| `ground/` | 256, 이음매 없이 반복 | 바닥 무늬. 땅(grass, plains, desert, tundra, snow, rock), 물(deep, shallow, lake, ice), 물가(shore_sand, shore_grass, shore_mud, shore_rock, shore_ice, shore_gravel). 식생을 걷어 내도 남는다. |
| `combo/` | 256, 삼각형 | 세 칸 꼭짓점의 완성 그림 (위 설명). 비어 있어도 된다. |
| `decal/` | 256 | 칸 위에 깔리는 그림. 식생 바닥(grass, forest, wetland ...), 시설 바닥(farm, district ...), road, road_alone, river, river_bank, shadow |
| `sprite/` | 128, 바닥 점 (64,124) | 세워 그리는 그림: 나무, 집, 탑, 천막 ... 그림자는 그리지 않는다 (따로 깔림). |

### 물가 무늬는 땅 종류마다 다르다

사막·평원·열대는 `shore_sand`, 습윤한 풀밭은 `shore_grass`, 습지는 `shore_mud`, 산지는 `shore_rock`, 눈·얼음은 `shore_ice`, 툰드라는 `shore_gravel`.

## 칸 하나를 그리는 순서

꼭짓점 바닥 (땅·물·물가·물거품, 또는 combo 그림) → 강둑 → 강물 → 식생 바닥 → 도로 → 시설 바닥 → 그림자 → 세운 그림

## 임시 그림 다시 만들기

`python3 art/tools/gen_placeholders.py` 가 땅·물·물가 바닥 무늬와 일부 변주를 만듭니다.
손으로 그린 기본 그림은 건드리지 않습니다. 진짜 그림으로 바꾼 파일은 이 스크립트를 다시 돌리면 덮어써지니,
진짜 그림은 PNG 로 넣거나 스크립트에서 그 항목을 빼 주세요.

그림이 제대로 읽히는지는 `godot --headless -s tools/art_sheet.gd -- 저장폴더` 로 한데 모아 볼 수 있습니다.
