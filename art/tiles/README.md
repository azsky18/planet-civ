# 타일 위 그림 (임시 그림)

문명3 처럼 상황마다 다른 2D 그림을 골라 쓰는 틀입니다. 지금 그림은 모두 이 프로젝트를 위해 새로 그린 임시 그림이고,
나중에 같은 이름의 파일을 넣으면 그대로 바뀝니다. **폴더에 파일을 넣기만 하면 게임이 읽습니다** (코드에 목록이 없습니다).
어떤 칸에 어떤 이름을 고르는지는 `scripts/tile_art.gd` 에 있습니다.

## 파일 이름 규칙

| 규칙 | 뜻 | 예 |
|---|---|---|
| `이름.svg` | 기본 그림 | `decal/grass.svg` |
| `이름.2.svg`, `이름.3.svg` ... | 같은 그림의 변주. 칸마다 정해진 하나를 골라 반복이 덜 보이게 한다. 몇 장이든 된다. | `ground/grass.2.svg` |
| `이칸__이웃.svg` | 이 칸과 이웃 칸의 조합에 쓰는 그림 | `edge/grass__desert.svg`, `shore/rock__ocean.svg` |
| `any` | 조합 그림이 없을 때 대신 쓰는 이름 | `shore/any__ocean.svg`, `edge/grass__any.svg` |
| `.png` | 같은 이름의 SVG 대신 PNG 를 쓴다 | `sprite/house.png` |

조합 그림은 `이칸__이웃` → `이칸__any` → `any__이웃` → (물가만) `any__any` 순서로 찾습니다. 하나도 없으면 그리지 않습니다.

## 폴더

| 폴더 | 크기 | 하는 일 |
|---|---|---|
| `ground/` | 256, 이음매 없이 반복 | 땅 바닥 무늬: grass, plains, desert, tundra, snow, rock. 식생을 걷어 내도 남는다. |
| `decal/` | 256 | 칸 위에 깔리는 그림. 식생 바닥(grass, forest, wetland ...), 시설 바닥(farm, district ...), road, road_alone, river_bank, shadow |
| `sprite/` | 128, 바닥 점 (64,124) | 세워 그리는 그림: 나무, 집, 탑, 천막 ... 그림자는 그리지 않는다 (따로 깔림). |
| `edge/` | 256 | 이웃 칸의 겉모습이 이 칸으로 번져 드는 경계. 위쪽 가장자리가 이웃과 닿는 변, 아래로 갈수록 옅어진다. |
| `shore/` | 256 | 땅과 물이 닿는 띠. 위 절반 물, 아래 절반 땅, 가운데 가로선이 물가. 가로로 늘여 쓴다. |
| `water/` | 256 | 물 칸 위에 얹는 그림 (deep, shallow, lake, ice) 과 강물 띠(river: 가운데가 물, 가로로 늘여 씀). |

### 칸의 겉모습 이름 (edge 에 쓰임)

땅: `grass` (습윤), `plains` (반건조), `desert` (건조), `tundra` (한대), `snow` (눈·빙설, 눈 덮인 산), `rock` (산지)
물: `deep` (깊은 바다), `shallow` (얕은 바다), `lake` (호수), `ice` (해빙)

### 물가 이름 (shore 에 쓰임)

땅 쪽: `sand` (사막, 평원, 열대), `grass` (습윤한 풀밭), `mud` (습지), `rock` (산지 절벽), `ice` (눈·얼음), `gravel` (툰드라)
물 쪽: `ocean` (바다), `lake` (호수)

## 칸 하나를 그리는 순서

바닥 무늬 → 경계 → 강둑 → 물가 → 강물 → 물 위 그림 → 식생 바닥 → 도로 → 시설 바닥 → 그림자 → 세운 그림

## 임시 그림 다시 만들기

`python3 art/tools/gen_placeholders.py` 가 바닥, 경계, 물가, 물 그림과 일부 변주를 만듭니다.
손으로 그린 기본 그림은 건드리지 않습니다. 진짜 그림으로 바꾼 파일은 이 스크립트를 다시 돌리면 덮어써지니,
진짜 그림은 PNG 로 넣거나 스크립트에서 그 항목을 빼 주세요.

그림이 제대로 읽히는지는 `godot --headless -s tools/art_sheet.gd -- 저장폴더` 로 한데 모아 볼 수 있습니다.
